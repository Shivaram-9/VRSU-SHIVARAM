# 🧠 VRSU Computer Vision & Deep Learning Lab Programs

This repository contains implementation of **13 Computer Vision and Deep Learning programs** using Python, OpenCV, TensorFlow, and PyTorch.

---

## 📌 Program 1: Point Processing & Image Enhancement

### (a) Histogram Equalization

Enhances image contrast by spreading pixel intensity values.

### (b) CLAHE

Improves local contrast and avoids noise amplification.

### (c) Color Enhancement

Enhances color quality using color space transformations.

### (d) Image Smoothing

Removes noise using filters like Gaussian Blur.

### (e) Image Sharpening

Enhances edges using Laplacian filtering.

---

## 📌 Program 2: Image Segmentation

### Otsu’s Binarization

Automatically finds threshold to separate foreground and background.

## 📌 Program 5: ML-Based Object Recognition

## 📌 Program 6: Deep Learning for Image Classification

## 📌 Program 7: Transfer Learning

Uses pretrained models (e.g., MobileNet) and fine-tunes for new tasks.

---

## 📌 Program 8: Feature Detection (SIFT)

Detects keypoints and descriptors invariant to scale and rotation.

---

## 📌 Program 9: Semantic & Instance Segmentation

Segments image into regions and identifies objects pixel-wise.

---

## 📌 Program 10: Stereo Vision Depth Estimation

Computes depth map using disparity between left and right images.

---

## 📌 Program 11: 3D Reconstruction

Reconstructs 3D structure using multiple 2D images and feature matching.

## 📌 Program 12: Robotic Navigation

Implements path planning (A*) for obstacle avoidance.

Extracts frames from video at regular intervals.
